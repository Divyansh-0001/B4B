# be4breach Frontend (Next.js)

Premium cinematic web experience for the be4breach public site and enterprise portal.

## Quick start

```bash
npm install
cp .env.example .env.local
npm run dev
```

## Quality

```bash
npm run lint
```

## Highlights

- Next.js App Router + TypeScript
- Tailwind CSS with cinematic glow system
- Framer Motion (client-only) micro-interactions
- Enterprise login + role-gated dashboard
- Skeleton loaders and lazy-loaded sections
